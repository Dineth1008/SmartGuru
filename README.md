# SmartGuru 🎓

A modern, robust Android application designed to streamline tuition class management. SmartGuru provides an intuitive platform for managing student attendance, payments, scheduling, and educational resources.

## ✨ Features
*   **Secure Authentication:** User login and registration powered by Firebase Authentication.
*   **Interactive Dashboard:** A modern UI built with Android Material Design (CardViews, Grid Layouts).
*   **Attendance Tracking:** (In Development) Seamless student attendance monitoring.
*   **Payment Management:** (In Development) Track and manage tuition fees effectively.
*   **Timetable Integration:** (In Development) Daily and weekly schedule overviews.
*   **Resource Center:** (In Development) Access to study materials and notes.

## 🛠️ Technology Stack
*   **Language:** Kotlin
*   **IDE:** Android Studio
*   **Backend/BaaS:** Firebase
*   **UI/UX:** XML, Material Design Components
